# Saga Atlas — World 2: Astral Nexus

Expansion of the Saga Map from a single 30-level world (Logic Garden) into a
scalable multi-world **Saga Atlas**, adding **World 2: Astral Nexus** (levels
31–60) as one continuous Candy-Crush-style scroll, gated behind a feature flag.

Everything is additive and reversible: set `featureFlags.enableAstralNexus =
false` and the map, unlock chain, registry, and preview modal all behave exactly
as they did before the expansion.

---

## What shipped

### Content & progression
- **30 new levels (31–60)**, deterministic & uniquely-solvable. Seeds in
  `puzzleSeeds.ts` (`world2-level-31-v1` … `-60`); generated by the existing
  engine with built-in uniqueness checking. Validated by `worldContent.test.ts`.
- **New `expert` difficulty tier** (58 holes) for levels 56–60. Curve:
  31–35 medium, 36–55 hard, 56–60 expert.
- **Tighter prestige targets**: 3★ thresholds carry a ×1.15 premium and crown
  target times are ×0.85 vs the same World 1 difficulty.
- **World-aware ids + unlock**: `levelIdForGlobal`, `nextLevelId` bridges
  `world1-level-30 → world2-level-31` (flag-gated), caps at 60.
- **Progress schema v2** (`unlockedWorlds`), non-destructive migration; the
  store repairs `unlockedWorlds` from completed levels on every hydrate / record
  / cloud-restore. The old World-1-only cloud-restore unlock derivation was
  fixed to be world-aware.

### Map (one continuous scroll)
- `worldRegistry` assembles World 1 + World 2 into a combined node list with a
  `PORTAL_GAP` between them; World 2 renders its **own** path / backdrop /
  landmark / particle layer instances (cosmic theme) so the path visibly
  **breaks** at the portal — a new destination, not the same rail continuing.
- `WorldUnlockPortal` (dormant → energize on level-30 clear → "Enter Astral
  Nexus" CTA), `WorldHeaderCard` ("Begin Level 31"), `WorldBiomeBackdrop` (act
  washes + starfield), scroll-driven backdrop atmosphere cross-fade (teal/gold →
  violet/cyan).
- `ActProgressHeader` generalized to all 6 acts across both worlds (centered,
  width-bounded stacked pill that never overflows).

### High-fidelity landmark sprites (both worlds)
- Both worlds' landmarks are now **premium Grok-Imagine sprites** rendered as
  large, animated, ambient **background set-pieces behind the path** (not
  procedural shapes). Shared renderer `LandmarkSprites`; thin per-world wrappers
  `WorldLandmark` (cosmic) and `GardenLandmark` (botanical) just load their
  sprite set. Radial pieces slowly rotate; all breathe; frozen on reduced motion.
- Sprites are generated on pure black, then **alpha is baked from luminance**
  (black → transparent) so they composite cleanly over the map — see
  `scripts/generate-world1-vfx.mjs` / `generate-world2-vfx.mjs` (`--reprocess`
  re-bakes alpha without re-calling the API). Art lives in
  `assets/map/world1/` and `assets/map/world2/`. The old procedural
  `GardenLandmarks.tsx` is superseded (no longer imported — safe to delete).

### Node ↔ path alignment fix (both worlds)
- Fixed a long-standing offset where the in-scroll node `stage` is pushed down
  by the world header, but the fixed Skia path/landmark overlays panned from
  y=0. `SagaMap` now measures the header height via `onLayout` and adds it to
  the layer `yOffset`, so nodes sit on the path and inside their landmarks (e.g.
  level 1 in the Seed Gate, level 60 in the Astral Core) across both worlds.

### Preview / competitive
- `LevelPreviewModal` + `levelPreviewService` now world-aware for levels 1–60:
  prestige copy ("Beat your best", "Reclaim Crown", "The pattern waits"),
  world-gate locked copy, Score-to-Beat, world accent. Tapping a node still
  opens the modal (never auto-launches). Supabase calls unchanged (string
  `level_id` already supports 31–60).
- Optional `RivalMarker` map glints behind `enableMapRivalMarkers`, fed from
  the preview store (no extra network; shows nothing without data).

### Game Center (scaffolded, gated)
- 2 leaderboards (`ASTRAL_NEXUS_STARS/CROWNS`), 3 achievements
  (`ASTRAL_NEXUS_UNLOCKED` 20, `ASTRAL_NEXUS_COMPLETE` 40, `ASTRAL_CORE_PERFECT`
  50 — total now **910**). New `REGISTERED_*` allowlists mean the service sends
  **nothing** to these ids until they exist in App Store Connect (no submit, no
  enqueue). World-2 achievement-evaluation + leaderboard submission wired in
  `leaderboardSubmissions.ts` and routed from `ResultsScreen`.
- Grok Imagine prompts for the 3 cosmic icons added to
  `scripts/achievement-icon-prompts.mjs` (cosmic `sharedNexus` chrome).

## Tooling note — Grok Imagine

The xAI Grok image MCP (`grok-imagine-image-mcp-server`) is installed globally
(user scope) for interactive use across projects. The repo's batch sprite
generation uses the REST API directly via the `scripts/generate-*-vfx.mjs` /
`scripts/generate-achievement-icons.mjs` scripts (read `XAI_API_KEY`). The
landmark VFX sprites (`assets/map/world{1,2}/`) are already generated and
committed; only the achievement icons below still need a run.

1. **Generate achievement art** (xAI/Grok):
   ```
   XAI_API_KEY=… node scripts/generate-achievement-icons.mjs --id astral_nexus_unlocked
   XAI_API_KEY=… node scripts/generate-achievement-icons.mjs --id astral_nexus_complete
   XAI_API_KEY=… node scripts/generate-achievement-icons.mjs --id astral_core_perfect
   ```

   exact ids/points/sort/copy in `docs/GAME_CENTER_SETUP.md`, upload 1024² sRGB
   art, then move the ids from the "pending" comments into `REGISTERED_*` sets
   in `gameCenterIds.ts`.

## Performance notes

- **No texture-limit risk.** Every Skia layer is a viewport-sized fixed Canvas
  panned by `-scrollY`; doubling the virtual scroll height (~8.9k → ~18.4k px)
  does **not** enlarge any Canvas — only the ScrollView content height grows.
- **World 2 layers are flag-gated** and only mounted when `enableAstralNexus`;
  with the flag off, World 1 pays exactly its original cost.
- **Particles within budget**: World 1 ambient 60 + World 2 ambient 80 = 140
  (spec budget 80–160). Reduced motion → both 0. World 2's pool is a second
  always-mounted Canvas to avoid a mid-scroll mount hitch.
- **Memoized geometry**: combined nodes, globalized layout, path segments, act
  washes, landmark specs, and cosmic orbs are all `useMemo`'d; scroll-linked
  values live in Reanimated worklets (no JS-thread hop per frame).
- **Decorative layers** are all `pointerEvents="none"` + accessibility-hidden;
  only `LevelNode` Pressables and the portal/header CTAs take touches.

**QA focus areas**: level-1 area (flag on vs off — must match), portal transition
(atmosphere cross-fade smoothness, one-shot energize), level-31 start (W2 pool
mount), the dense level-45 Starfall Archive glyph cluster, the level-60 Astral
Core animation, modal open/close, and a full reduced-motion scroll.

## Known limitations

- **World 2 achievement art** is not yet generated (operator step above);
  `<AchievementGlyph>` shows the tier-coloured placeholder until then.
- **Game Center World 2 ids are inert** until registered in ASC + added to the
  allowlists (by design — prevents broken submissions).
- **`ASTRAL_NEXUS_UNLOCKED`** fires on the first World 2 level *completion*
  (entering the Nexus), not the instant level 30 is cleared. Simpler + idempotent.
- **In-app gallery progress bars** aren't wired for the count-based
  `ASTRAL_NEXUS_COMPLETE` (no World 2 snapshot in `AchievementsScreen`); it still
  renders with name/desc/tier/unlock state.
- **Particle presets are unified per world** (one cosmic palette across all 3
  World 2 acts) rather than per-act (prism_shards / star_motes / orbital_gold) —
  a future refinement.

## Adding World 3 (roadmap)

The registry pattern makes a third world mechanical:

1. **`worlds.ts`** — add `WORLD_3` and push to `WORLDS`.
2. **`worldThemes.ts`** — add `WORLD_3_THEME` + new `colors.*` tokens.
3. **`world3Layout.ts`** — `WORLD_3_NODE_LAYOUT` (global levels 61–90, local y),
   `WORLD_3_ACTS`, `getWorld3ActForLevel`. Widen `MapBiome` / `MapLandmark` /
   `WorldActId` unions in `mapLayout.ts`.
4. **`worldRegistry.ts`** — add a `WORLD_3_DEF` (yOrigin = World 2 end + gap),
   include it in `ALL_WORLD_DEFS`. `buildCombinedNodes` / `getActBuckets` /
   `combinedContentHeight` pick it up automatically.
5. **Content** — `puzzleSeeds.ts` 61–90, `levels.ts` `WORLD_3_LEVELS` +
   difficulty curve; `nextLevelId` already crosses worlds by global index.
6. **Unlock rule** — `worldUnlockRules.ts`: add a `WORLD_UNLOCK_REQUIREMENTS`
   entry (e.g. complete level 60). `deriveUnlockedWorlds` extends naturally.
7. **VFX** — render World 3 instances of the parameterized layers
   (`AnimatedLogicPath`, `ParticleField`, `WorldBiomeBackdrop`, `WorldLandmark`)
   in `SagaMap` behind a `enableWorld3` flag; add a second `WorldUnlockPortal` /
   `WorldHeaderCard` in the new gap.
8. **Game Center** — add broad `WORLD_3_STARS/CROWNS` leaderboards + a few
   achievements (mind the 1000-point cap; 90 headroom remains), gated by the
   `REGISTERED_*` allowlists.
9. **QA** — extend `worldContent.test.ts` and the checklist above.
